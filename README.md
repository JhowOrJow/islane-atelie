# Islane Veloso • Ateliê de Estética (Manicure e Pedicure)

Site/catálogo estático feito com **HTML + CSS + JavaScript**, com as bibliotecas:
Swiper (carrossel do catálogo), GLightbox (galeria), AOS (animações) e Font Awesome (ícones).

## Editar conteúdo
Tudo (telefone, serviços, preços, galeria, mensagem de aniversário) fica em `js/data.js`.

## Rodar local
Abra `index.html` no navegador, ou: `npx serve .`

## Publicar no Render
New + > **Static Site** > escolha este repositório > Build Command: *(vazio)* > Publish Directory: `.`
